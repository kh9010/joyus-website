the centerpiece

The Architect — where the eight bets converged.

H5 · Defer to the human

The AI proposes the spec. The user accepts, edits, or asks for more. Confirmation required at every step — never assumed.

H6 · Draft state matters

The spec lives as an editable draft, not a frozen brief. Refinement is the primary action, not the exception.

H4 · Completeness over Simplicity

Detailed parameters, architect chat, and the spec link — all available at once. Density is intentional.

H8 · Users want it done

Generate is one click away even when the spec is rough. The output unlocks the conversation about how to refine it.

the decision behind the front door

The original landing assumed an expert with a focused need. Almost nobody is one.

The research put fewer than 10% of users — probably 2–5% — at the "creates solution" state the old page was built for. So the landing was redone for the other 95%: the user promise rewritten to create space to find inspiration and refine their thinking about the problem before starting. The headline itself does the work — a bracket that rotates through real supported workflows, so the page demonstrates breadth instead of asserting it.

Functions on display

Community-built function cards showcase the breadth and depth of the tool — answering "what can I even do here?" before anyone asks it.

Persistent left nav

Create / My Library / Explore stay pinned from the first screen — grounding and context never disappear.

Refining the pages to support curiosity brings more kinds of people into the experience — even when they don't have an articulated need yet.

four surfaces, one logic

Landing. Architect. Explore. Run. Same grammar throughout.

Every screen earns its density. Every interaction respects the user's emotional state. The architect chat is the soul; landing and run are the front door and the proof — and Explore is the room where trust gets built. The visual grammar carries one set of values across all four: space, flexibility, and play.

the front door

Landing

The public face. Every word tested against "would an engineer trust this?"

the soul

Architect

A conversational spec editor. The AI proposes; the user disposes. The interface is the onboarding. The chat coaches users through initial creation — and the UX holds them through the final refinement, after the solution is generated.

the trust-builder

Explore

"Functions. Pipelines. Tools. Generators." A browsable library of community-built tools — it shows the value of the product and gives more starting points for adapting a use case. This is the "refines need" middle the journey was missing, made into a page.

the proof

Run

A generated function, running. Inputs, outputs, logs — the whole runtime made legible.
